1. Installation

Install Kikimo on a Windows computer that will serve as the local point-of-sale terminal.

Step 1

Download

Get the latest Kikimo installer from the authorized source provided by the business owner or administrator.

Step 2

Run installer

Double-click the setup file and follow the installation wizard on the target Windows device.

Step 3

Open app

Launch Kikimo after installation completes. The app may ask for activation before it can be used.

Important: Use a trusted Windows device with a stable local database and adequate permissions. The app stores sales and stock data on the local machine.

2. Activation

Activation is required before the application can be used for daily operations.

What to do

Ask the owner or administrator for the activation code for this device. Enter the code in the activation screen shown by the app when you first open it.

Note: Do not attempt to generate or share activation keys yourself. The code is assigned by the owner and is linked to the specific machine.
  • Use the exact machine activation code provided for this device.
  • Do not try to reuse a code from another computer.
  • If the code is missing or not accepted, contact the owner or administrator.

3. Sign in

After activation, sign in with your assigned user account and PIN.

Role Typical access
Administrator Full access to products, sales, reports, team accounts, and configuration
Attendant Sales, daily totals, and limited operational access
Security: Always sign out when leaving the terminal, and keep your PIN private. Do not share account credentials between staff members.

4. Sales and checkout

Kikimo is designed for fast in-store retail sales on a Windows device.

Basic checkout flow

  1. Sign in to your assigned terminal.
  2. Search for a product or scan its barcode.
  3. Add items to the cart and adjust quantities if needed.
  4. Choose a payment method such as cash, M-Pesa, card, mixed payment, or customer credit.
  5. Review the total, tender, and change.
  6. Complete the sale and print the receipt.

Useful sales features

  • Hold an order and resume it later
  • Apply promotional discounts if configured
  • Review product expiry information during checkout
  • Record partial customer payments and balances
  • Reprint receipts from sales history

5. Products

Use the product module to create, edit, and manage your store catalogue.

  • Create and update products with SKU, barcode, price, stock, image, and expiry details
  • Deactivate products that are no longer sold
  • Import products using CSV or Excel files
  • Download a template to prepare import files

Recommended product hygiene

  • Keep standard SKUs and barcode values consistent
  • Check expiry dates before promotions or large stock purchases
  • Update prices carefully when a supplier changes cost

6. Inventory and stock management

Track stock activity to keep retail operations accurate and reduce shortages.

  • Review low-stock warnings and inventory summaries
  • Record purchases, adjustments, and wastage
  • Monitor stock movements and batch history
  • Print shelf labels for selected products
  • Manage measured stock using parent stock and split batch opening
Measured stock: For measured products, open parent stock into batches and sell from the oldest open batch first. This keeps stock movement records consistent and helps with FIFO-based inventory tracking.

7. Reports and dashboard

Use reports to track sales, cashier activity, low stock, and store performance.

Daily overview

Check sales totals, transaction counts, and daily vendor or cashier performance.

Product trends

Review best-selling products and revenue by item.

Payment mix

See how much revenue came through cash, card, M-Pesa, or credit.

  • Review date-range sales reports for revenue and profit
  • Export report data to CSV when needed
  • Review stock and performance trends before ordering new stock

8. Settings and store configuration

Administrators can configure store details, user access, and device settings.

  • Update store name, address, and receipt details
  • Choose the app theme and visual layout
  • Review local database storage information
  • Check activation status and terminal information
  • Lock the workstation or workspace when needed
Cloud sync: Any optional cloud sync or remote integration must be configured only by the owner or system administrator through a secure backend. Do not enable or edit this without approval.

9. Troubleshooting

Problem Check
Activation failed Confirm you have the correct activation code for this device and contact the owner if it is missing.
Product not found Check barcode, SKU, and whether the item was deactivated.
Receipt not printing Check the printer connection, queue state, and print settings.
Low stock warnings Review stock availability, restock plans, and measured batch records.
Unexpected app behavior Restart the app and contact the owner if the problem continues.
